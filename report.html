Delivery-Level Algorithmic Formulation

Mathematical Definition of Pressure

Pressure is formulated as a dynamic, ball-by-ball leverage vector rather than an arbitrary over cutoff.

1. The Multi-Variable Pressure Formulation & Neutral Defaults

Every delivery $i$ across the 80,498 deliveries in the 2025–2026 data pack is assigned a composite Pressure Weight ($W_i \in [1.00, 2.25]$):

W_i = 1.00 + (c_phase * I_phase) + (c_rrr * I_rrr) + (c_wkt * I_wkt) + (c_margin * I_margin)

Where $I_k \in \{0, 1\}$ represents the active binary indicator condition, and weights are empirically calibrated:

  • Neutral Baseline Default ($W_i = 1.00$): When no pressure condition triggers are active (e.g. middle overs 8–14, first innings, run rate 7.5, 2 wickets down), $W_i = 1.00$ exactly.
  • Phase Leverage ($c_{ ext{phase}}$): Overs 16–20 activate $c_{ ext{death}} = +0.50$; Overs 1–6 Powerplay activate $c_{ ext{pp}} = +0.10$; Overs 7–15 activate $c_{ ext{mid}} = +0.20$.
  • Required Run Rate Stress ($c_{ ext{rrr}}$): In 2nd innings, triggers $+0.30$ when $ ext{RRR} \ge 10.0$ RPO, scaling continuously: $$c_{ ext{rrr}} = \min\left(0.50, 0.30 imes rac{ ext{RRR}_i}{10.0} ight)$$
  • Wicket Depletion Strain ($c_{ ext{wkt}}$): Triggers $+0.25$ when team wickets in hand $\le 4$.
  • Razor-Margin Stress ($c_{ ext{margin}}$): Triggers $+0.20$ when winning margin $\le 18$ runs or balls remaining $\le 18$.

2. The Relative Clutch Index (RCI)

Aggregate runs or wickets often reward players feasting in low-leverage situations. The Relative Clutch Index isolates genuine match-winning value by evaluating performance under high pressure ($W_i \ge 1.40$) relative to personal baselines:

Batting Relative Clutch Index (RCI_Bat)

RCI_Bat = SR_Press * [ 1 + (SR_Press - SR_Base) / SR_Base ] * (1 - DotRate_Press) * (1 + BndRate_Press)

Bowling Relative Clutch Index (RCI_Bowl)

RCI_Bowl = [ 1 / (Econ_Press + 0.01) ] * (DotRate_Press) * (1 - BndConceded_Press) * [ 1 + (Wickets_Press / Balls_Press) * 6 ]

3. Scarcity & Early-Buy Multipliers

To identify the next Vignesh Puthur, candidate scores are scaled by an Asymmetry Multiplier ($A_p$):

  • Age Sweet-Spot ($19 \le ext{Age} \le 25$): Multiplier $1.25 imes$. Peak athletic upside and multi-year developmental runway.
  • Skill Scarcity ($S_p$): Left-arm 140+ km/h pace ($1.30 imes$), Mystery wrist-spin ($1.25 imes$), 200+ SR Death Finisher ($1.30 imes$).
  • Purse Efficiency ($E_p$): Uncapped base price (INR 20L–30L) with high statistical output ($1.20 imes$).
