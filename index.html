Methodology & Mathematical Formulation

Dynamic leverage vector applied across 80,498 match deliveries.

1. Dynamic Pressure Weight

Every delivery is assigned a contextual weight (W_i in [1.00, 2.25]):

W_i = 1.00 + (c_phase * I_phase) + (c_rrr * I_rrr) + (c_wkt * I_wkt) + (c_margin * I_margin)

Neutral baseline default is W_i = 1.00 when no stress trigger is active (middle overs, normal run rate).

2. Relative Clutch Index (RCI)

Evaluates execution under high pressure (W_i ≥ 1.40) relative to personal baselines:

RCI_Bat = SR_Press * [1 + (SR_Press - SR_Base)/SR_Base] * (1 - DotRate_Press) * (1 + BndRate_Press)

Eliminates flat-track inflation in low-leverage phases.

3. Vignesh Puthur Scarcity Model

Replicating Season 1's winning discovery, candidate rankings apply an Asymmetric Scarcity Multiplier (A_p):

19–25 age runway (1.25x), left-arm 140+ pace (1.30x), mystery wrist-spin (1.25x), and 200+ death SR (1.30x).

4. Screening Constraints
